# IRONLOG

Mobile-first offline workout tracker built with React, TypeScript, Vite and IndexedDB.

## Run

```bash
npm ci
npm run dev
```

## Validate

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm run test:e2e
```

## GitHub Pages

Push to `main`. The included GitHub Actions workflow validates the project and deploys `dist` to GitHub Pages. In the repository, set **Settings → Pages → Source** to **GitHub Actions**.
